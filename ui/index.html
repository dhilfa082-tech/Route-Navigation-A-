About this project

This page runs the same logic as the Python project in the browser, with no server and no internet needed.

CSP layer: green times of NS, EW and TURN are variables (15-60 s). The cycle is fixed at 90 s, every phase gets at least 15 s, and a busier phase gets at least as much green as a less busy one. Plain backtracking and forward checking are both run so you can compare the assignments tried.

Rule layer: R1 Accident(e) → Blocked(e); R2 Rain ∧ Night → SpeedFactor(0.7); R3 EmergencyVehicle(v) → GreenCorridor(route). Forward chaining fires the rules until nothing new appears, then A* plans again.

Uncertainty and fairness: every road is LOW, MEDIUM or HIGH congestion with probabilities that depend on the hour. A* minimises the expected travel time. School and residential roads get a penalty when fairness is ON.

Limits: the map and the data are synthetic. This is a teaching project and not a deployable traffic-control system.
